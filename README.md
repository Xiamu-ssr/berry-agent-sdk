# Berry Agent SDK

A TypeScript SDK for building long-running, resumable, hot-swappable AI agents.

> See [**AGENTS.md**](./AGENTS.md) for the full overview — lifecycle, runtime directory layout, and module introductions (context / memory / skill / mcp / tools).

## Install

```bash
npm install @berry-agent/core @berry-agent/models
```

Optional packages: `@berry-agent/memory-file` · `@berry-agent/mcp` · `@berry-agent/observe` · `@berry-agent/safe` · `@berry-agent/team` · `@berry-agent/tools-common`.
