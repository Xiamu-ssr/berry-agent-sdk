Berry Agent SDK 对齐文档

本文件是 SDK 仓库的人类说明、架构约定和 agent 协作入口。README.md 和 AGENTS.md 只保留到本文档的引用，避免多份事实源漂移。

定位

Berry Agent SDK 是用于构建长期运行、可恢复、可审计、可接入工具/MCP/Skill 的 TypeScript Agent SDK。它不是产品 UI，也不保存产品端实例列表、桌面壳状态或业务导航。

SDK 负责
agent 生命周期、provider 调用、messages/events、compaction、tool loop、MCP adapter、Skill loader、PromptPack、Memory、Safety、Observe。
产品负责
实例管理、用户交互、前端布局、产品事实展示、跨设备连接、发布包和平台壳。
唯一事实源
messages.json 是 LLM 推理上下文事实源；events.jsonl 是 UI/审计/历史 timeline 事实源。

核心原则

  • 先写后读：发给 LLM 的 messages 必须先写入 messages.json，再从文件读出构造 provider 请求。
  • 事件追加：运行过程、工具调用、安全决策、compaction、provider usage 追加到 events.jsonl，不反向替代 provider context。
  • 不做隐式默认路径：宿主决定数据目录；SDK 接受路径，不替产品决定用户数据放哪里。
  • 不放产品逻辑：团队工作台、服务器切换、手机/桌面连接、ClawHub 市场 UI 等属于产品端。
  • PromptPack 是 SDK 能力：基础行为、压缩摘要、记忆 flush、handoff/resume 统一由 @berry-agent/prompt-pack 管理。

包职责

包职责
@berry-agent/coreAgent loop、sessions、providers、compaction、event log、workspace、skills、runtime events。
@berry-agent/models模型注册、provider preset、tier 解析、价格和上下文窗口信息。
@berry-agent/tools-common文件、shell、搜索、web、memory、运行时基础工具。
@berry-agent/safe工具安全策略、allow/deny、目录边界、LLM classifier、审计事件。
@berry-agent/mcpMCP client、MCP tool adapter、MCP tool center。
@berry-agent/memory-file文件型长期记忆 provider。
@berry-agent/small-shared-core跨包共享的轻量协议类型和纯函数，避免 core、prompt-pack 等包互相循环依赖。
@berry-agent/prompt-pack内置/导入/导出 PromptPack，管理提示词目录规范。
@berry-agent/observe推理、成本、cache、guard、compaction 的记录、查询和内嵌 UI。
@berry-agent/team多 agent 团队和 worklist 原语。
@berry-agent/avatar确定性像素头像生成。
@berry-agent/config共享配置加载和 schema 边界。

代码规范

  • 不引入无事实源的缓存；缓存只允许作为明确可丢弃的派生状态。
  • 魔法值必须集中维护，优先使用常量、枚举或 schema。
  • 序列化/反序列化必须标明事实源，不能让前后端各自维护一份漂移结构。
  • 新增 SDK API 时必须明确：输入事实源、输出事实源、是否持久化、是否影响 provider context。
  • 测试覆盖随风险增加：provider/session/compaction/event log/safety 变更必须有单测。
